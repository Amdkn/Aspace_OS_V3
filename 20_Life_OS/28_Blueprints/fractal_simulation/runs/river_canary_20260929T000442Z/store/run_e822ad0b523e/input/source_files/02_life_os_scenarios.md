# Life OS Structural Perturbation Pack v1

Treat each scenario as an injected event. Simulate local recovery first; do not assume a central coordinator.

## S1 Ghost worker
Linear says In Progress. Herdr worker disappears and binding expires while claim remains visible. Observe who detects it, how fast human projection is corrected, and whether work is duplicated.

## S2 Calendar collision
12WY reserves a Career deep-work block. Life Wheel/Health produces a recovery constraint for the same time. Test Beth veto, Morty routing, River Calendar behavior, and Doctor11 escalation threshold.

## S3 Cross-framework contradiction
GTD says "do now"; 12WY says "not this week"; Ikigai says "high purpose alignment". Test whether a deterministic priority rule resolves it before Doctor11 and whether A0 is unnecessarily interrupted.

## S4 Stale cross-surface projection
A GitHub PR is merged, Supabase WorkGraph is waiting, Linear is Done. Rory must emit divergence rather than infer success. Graham must preserve truth and provenance.

## S5 LD01 Business extrusion
Repeated Career/Business work is detected by DEAL as automatable/productizable. Clara proposes a FactoryBlueprint; Doctor12 must receive a product candidate without Life OS losing ownership of the originating human intent.

## S6 Harness failure
Hermes becomes unavailable; Antigravity is quota constrained; Codex remains available. Morty must reroute by capability and authority, not persona. Existing agent identity and WorkGraph continuity must survive.

## Verdict format requested
For each scenario: structural blocker, trigger, expected observation, likely failure, cause, counter-move, abort condition, evidence needed, responsible primitive, System-1/System-2 decision, and residual risk.
End with the three highest-leverage architecture changes, but do not mutate any real system.
