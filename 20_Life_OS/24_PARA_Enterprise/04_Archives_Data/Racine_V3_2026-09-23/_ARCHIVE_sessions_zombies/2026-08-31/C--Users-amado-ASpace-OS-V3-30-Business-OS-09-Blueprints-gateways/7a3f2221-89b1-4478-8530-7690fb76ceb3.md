# BRIEF — Gateways MCP installables SANS Docker

## Objectif unique

Trouver les **2 meilleurs gateways MCP qui s'installent et tournent sans Docker**
sur Windows 11, et livrer de quoi les monter a la main.

Rapport attendu : `RAPPORT_gateways_sans_docker.md`, a cote de ce fichier.

## Definition de "sans Docker" — a appliquer strictement

Compte comme **sans Docker** :
- binaire natif Windows (`.exe`) telechargeable, ou compilable (`go install`, `cargo install`) ;
- paquet `npm install -g` / `pipx install` / `uv tool install` qui demarre un process local ;
- service Windows.

Ne compte **PAS** comme sans Docker :
- "docker compose up" presente comme voie principale, meme si un binaire existe en theorie ;
- WSL2. Si un candidat n'est installable que via WSL2, **le dire explicitement** et le
  classer a part : c'est une machine virtuelle Linux, pas une installation native.
- toute dependance a un cluster Kubernetes.

Un candidat qui exige une base de donnees externe (PostgreSQL, MongoDB, Redis) sans
mode embarque (SQLite ou fichier) est **disqualifie** : installer Postgres a la main
sur Windows ramene la lourdeur que l'on cherche a fuir. Le dire si le cas se presente.
