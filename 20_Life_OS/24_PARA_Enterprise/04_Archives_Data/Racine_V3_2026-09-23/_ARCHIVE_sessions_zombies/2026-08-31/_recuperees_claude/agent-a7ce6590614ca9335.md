# Scope de cet ADR

Décider et documenter les **standards WCAG 2.2 AA obligatoires** pour les Landing Pages OMK Nexus :

1. **Perceivable (Principe 1)** :
   - Textes alternatifs sur SVG inline (toutes les images/icônes décoratives = `alt=""`, informationnelles = `alt="..."`)
   - Sous-titres pour vidéos (cadre QA : si ajout image gen, contrat `alt`)
   - Contraste WCAG 2.2 AA : ratio 4.5:1 pour texte normal, 3:1 pour large text (>=18pt regular ou 14pt bold)
   - Pas de couleur seule comme signal (errors avec icône + texte)

2. **Operable (Principe 2)** :
   - Keyboard navigable : tab order logique, focus-visible custom (oxblood/teal/amber par cohérence landing)
   - Pas de piège au clavier (modals ESC-fermable)
   - Skip-nav link si multi-page
   - Touch target 44×44px min (mobile)
   - Motion : `prefers-reduced-motion: reduce` désactive animations/scroll
   - Pas de flash > 3x/sec (sécurité photosensibilité)

3. **Understandable (Principe 3)** :
   - Lang explicite : `<html lang="fr">`
   - Headings hiérarchiques : 1 seul `<h1>` par page, `<h2>`/`<h3>` ordonnés
   - Form labels explicites (chaque `<input>` a un `<label>`)

4. **Robust (Principe 4)** :
   - HTML valide (parser-compatible)
   - Custom cursor avec fallback `auto` si SVG fail
   - Pas de dépendance JS pour naviguer (peut lire sans JS)

5. **Process de QA A11y par landing** :
   - Test Playwright headless axe-core (audit auto) — D1 receipts
   - Test keyboard navigation manuel (sub-agent ou A0)
   - Test lecteur d'écran narratif (NVDA VoiceOver)
   - Browser dev tools a11y inspector

6. **Anti-patterns interdits** :
   - `outline: none` sans replacement focus-visible
   - Buttons sans contexte (`<button>X</button>` sans `aria-label`)
   - `tabindex > 0` (destructeur de tab order)
   - Vidéo auto-play avec son
   - Formulaire sans validation message clair
