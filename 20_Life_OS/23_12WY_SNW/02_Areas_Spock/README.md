# 02_Areas_Spock — Responsabilités continues (PARA A3)

Rôle de rangement : toute responsabilité continue sans échéance finale —
santé, finances, relations, maintenance. Rangs sous l'autorité Spock (Areas).

Une area est entretenue, jamais « terminée » ; elle se cadence par les
disciplines 12WY (Planning/Focus/Metrics/Execution).
