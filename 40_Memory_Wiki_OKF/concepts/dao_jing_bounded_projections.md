# Persistent truth, bounded view
COMPANIONS_CONSTITUTION.json defines nine stable companion identities and their
vertical authority boundaries. Its horizontal typed handoff loop closes through
WorldState. A harness is an effector, and a home core is stewardship, not exclusivity.

dao_jing.py reads a consistent SQLite snapshot for Rick, three Doctors and nine
Companions. It emits typed evidence metadata with explicit item and UTF-8 byte bounds.
No projection can grant authority or mutate WorkGraph. A lease alone never proves
execution. Drift is returned as data, never silently repaired by a UI.
