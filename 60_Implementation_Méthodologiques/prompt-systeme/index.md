Ce sous-bundle porte ce qui se rédige **une fois** et vaut pour toutes les tâches : prompt système, contrat de session, patterns positifs et négatifs, points de référence, bornes opérationnelles, alias.

La règle qui le gouverne : *plus un artefact est multiplicatif, plus on ralentit pour l'écrire à la main.*
