# GitHub Primitive Topology

Canonical source in-repo: [GITHUB_PRIMITIVE_TOPOLOGY_V4.md](https://github.com/Amdkn/Aspace_OS_V3/blob/main/docs/governance/GITHUB_PRIMITIVE_TOPOLOGY_V4.md)

| Primitive | Use |
|---|---|
| Discussion | exploration, hypotheses, RFC, research |
| Wiki / docs | stable doctrine, vocabulary, playbooks |
| Project | portfolio, possibility-space, sequencing |
| Milestone | bounded convergence, release/certification |
| Issue | executable or concretely blocked cell |
| Pull Request | mutation + review + proof |
| Action / Check | deterministic verification |
| Release | immutable promotion |
| Agent profile | versioned GitHub-hosted embodiment |
| Webhook / GitHub App | bridge to external runtimes |

## Branch law

ChatGPT branches preserve conversational exploration.

Git branches carry short-lived mutations only:

`branch → PR → CI/review → merge → delete`

Do not preserve institutional memory by keeping feature branches alive.
