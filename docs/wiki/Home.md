## Operating law

GitHub is a control plane and durable engineering surface. It is not the runtime, the institutional brain, or a universal source of truth.

Use the primitive that matches the semantic object:

Discussion → explore  
Wiki/docs → explain canon  
Project → organize portfolio  
Milestone → converge  
Issue → execute/block  
PR → mutate/prove  
Action → verify  
Release → promote
