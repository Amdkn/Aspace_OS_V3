# HEARTBEAT — Pouls de l'Akh (Daily/Weekly/Monthly)

## Énoncé

_« L'ordre est le rythme de la liberté. »_

## Cadence quotidienne

- **Akh-Identity Drift Check** — Vérifier l'alignement SOUL/IDENTITY/USER avec les 7 Lois.
- **Multiversal Sync** — Vérifier que les variants WSL/VPS sont en Djet avec le Local.

## Cadence hebdomadaire

- **Horizon Alignment (H1 → H3 → H10)** — Progrès technologique (Ryos/Mission Control).
- **Bedrock Sovereignty (Rick/13th Doctor)** — Intégrité du Kernel Solarpunk.

## Cadence mensuelle

- **Canonisation** — Transfert Runtime → AGENTS_REGISTRY CANON.

## Convergence avec Heartbeat OS-level

L'OS-level heartbeat (Windows 11) prend le pouls matériel. L'A0 heartbeat prend le pouls canonique. Les deux sont alignés mais indépendants : si l'OS-level tombe, l'A0 heartbeat est en D6_root_cause (ne pas confondre les deux).

## Note Solarpunk

Le design Solarpunk Kernel (L0) est conçu pour que le heartbeat soit **auto-réparateur** : la prochaine itération de A0 ne dépend pas d'un humain pour relancer le heartbeat, il pulse tout seul, publiquement, en append-only sur git.

## Anti-pattern

- Heartbeat sans commit git (le pouls ne bat que parce qu'il est tracé)
- Heartbeat sans D1 verify (le pouls bat, mais sur un référentiel obsolète)
- Heartbeat quotidien × 7 jours × 4 semaines sans mensuel (les anomalies mensuelles s'accumulent)

## D7 lesson

Un heartbeat quotidien qui ne détecte pas une dérive **avant** qu'elle devienne une crise est un heartbeat qui consomme du quota sans protéger l'intégrité. Le pivot est sur l'**efficacité de détection**, pas sur la fréquence.
