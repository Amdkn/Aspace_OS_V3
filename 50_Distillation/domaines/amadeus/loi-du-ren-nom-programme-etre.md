# La Loi du Ren — le nom programme l'être

## Énoncé

Les Égyptiens gravaient le nom des ennemis sur des poteries puis les détruisaient. Détruire le nom = détruire la personne. Loi du Ren : **« Je suis nul, je suis fatigué » — tu graves ta propre sentence dans la pierre.**

## Application A'Space

A0 programme la réalité en nommant les Visionnaires (A1) et en leur déléguant l'Intention. **Nommer, c'est invoquer.**

| Cible | Action |
|-------|--------|
| A0 → Rick Sanches | Loi du Cœur (L0 Bedrock) |
| A0 → Beth & Morty | Loi de Ma'at (L1 Life OS) |
| A0 → Jerry & Summer | Loi de Kheper (L2 Business Pulse) |

## Pourquoi cette doctrine est-elle centrale ?

Le naming crée l'identité : un agent nommé (Rick, Beth, Morty) porte son archétype, ses frontières, sa Loi. Sans nom, l'agent est une fonction sans âme. Le mapping complet Kémétique × A'Space :

| Loi | Principe | A'Space Mapping |
|-----|----------|-----------------|
| Kheper | Transformation naît du chaos | Cerritos (GTD) |
| Ma'at | État présent, pas passé | Beth (Veto) |
| Ren | Le nom programme l'être | Orville (Ikigai) |
| Sia | Perception filtrée | Discovery (Life Wheel) |
| Cœur > Cerveau | Noyau > Calcul | Rick (L0 Bedrock) |
| Akh | Alignement total | SNW (12WY) |
| Heka | Parole créatrice | Protostar (DEAL) |

## Anti-pattern

« Je suis nul, je suis fatigué » — se nommer soi-même par ses limites. Le Ren retourne contre celui qui l'énonce.

## Source Kémétique

Les Égyptiens gravaient le nom des ennemis sur des poteries puis les détruisaient. Détruire le nom = détruire la personne. (Arché-Futurisme §3)
