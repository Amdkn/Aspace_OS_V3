# AaaS 3 variants — Solaris, Nexus/OMK, Orbiter/ABC

AaaS (Agency as a Service) est l'**offre canonique** d'A'Space OS en trois variantes, chacune ancrée sur un LD Discovery. Plan §3.4 verrouille le mapping ; le 4e variant est dormant.

## Table canon des 3 (4) variants

| Variant AaaS | Domaine A0 | A3 Ancre | Horizon | Statut canon |
|---|---|---|---|---|
| **Solaris** | Civilisation Kardashev Type 3 | **Book** (LD01 H1) | H90 Legacy 1000T par valeur Solarpunk | ACTIF Q3 2026 |
| **Nexus (OMK)** | Société Solarpunk | **Saru** (LD02 H3) | H3 Indépendance financière | **CLOS 2026-06-20** |
| **Orbiter (ABC)** | OS Family Offices | **Burnham** (LD06 H10) | H10 Patrimoine baby-boomers | ACTIF Q3 2026 |
| **[4e Dormant]** | Family/Home LD03+LD04 | Tilly/Culber | Reveil Q4 2026 / Q1 2027 | dormant |

## Solaris — Book LD01, Kardashev Type 3

- **A3 ancre** : Book (H1 weekly P&L).
- **Horizon canon** : **H90 Legacy 1000T** par valeur Solarpunk/biomimétisme (Benyus/Aberkane).
- **Objectif** : A'Space OS = architecture pour une nouvelle économie, pas seulement un shield personnel.
- **Statut** : ACTIF Q3 2026.
- **Anti-paperclip** : Book supervise Saru H3 contre paperclip maximizer.

## Nexus / OMK — Saru LD02, Solarpunk Society

- **A3 ancre** : Saru (H3 quarterly runway).
- **Horizon canon** : **H3 Indépendance financière**.
- **Objectif** : société Solarpunk — autonomy + biomimétisme.
- **Statut** : **CLOS 2026-06-20** (OMK BOS sprint `dcc1235` ✅ livré+mergé+déployé).
- **Conséquence** : Saru libéré pour visions plus longues (H10+) post-CLOS.

## Orbiter / ABC — Burnham LD06, Family Offices

- **A3 ancre** : Burnham (H10 family cycle).
- **Horizon canon** : **H10 Patrimoine baby-boomers** (centaines de T).
- **Objectif** : OS Family Offices — Asset-Based Community.
- **Statut** : ACTIF Q3 2026.
- **Couplage** : Item 1 cycle 12WY Q3 2026 — "Introduction de SOB à Abdaty" → Burnham supervise l'engagement famille/présence.

## 4e Dormant — LD03/LD04 Family/Home

- **A3 ancres** : Tilly (LD04) + Culber (LD03).
- **Horizon canon** : à définir au réveil.
- **Réveil prévu** : Q4 2026 / Q1 2027.
- **Statut** : dormant.

## Karpathy loop sur les variants

Pour chaque variant actif, Karpathy loop D→E→A→L appliquée :

1. **D Define** : quel outcome canon (Solairis : 1000T Solarpunk ; OMK : indé finance ; ABC : patrimoine).
2. **E Eliminate** : quelles étapes NO-GO.
3. **A Automate** : quels skills créer.
4. **L Liberate** : D11 bandwidth measurement.

## Convergence Solaris/Orbiter Cycle Q3 2026

W4 (08/17 → 09/07) du cycle 12WY Q3 2026 porte Items 7-12, dont **structuration Solaris/OMK/ABC parallel**. Le fait qu'OMK soit CLOS permet à Chapel (Metrics) et Ortegas (Execution) de focaliser sur Solaris + Orbiter avec Saru comme superviseur résiduel.
