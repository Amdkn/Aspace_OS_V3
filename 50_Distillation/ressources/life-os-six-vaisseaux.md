# Life OS — six vaisseaux L1 et leurs frameworks

> L1 Life OS est le second layer de la Matrioshka — entre L0 Tech OS (Rick's bedrock) et
> L2 Business Pulse (Jerry & Summer's fractal). Il gère le **sens de la vie** et
> l'exécution personnelle.

## 1. Les 6 vaisseaux

| Ship | A2 Captain | Framework | Mission | Focus |
|---|---|---|---|---|
| **USS Orville** | Orville | Ikigai | Meaning | Pourquoi je fais ça ? |
| **USS Discovery** | Discovery | Life Wheel | Balance | Équilibre 8 domaines de vie |
| **USS SNW** | SNW | 12WY | Execution | 12 semaines = un cycle |
| **USS Enterprise** | Enterprise | PARA | Structure | Projects / Areas / Resources / Archives |
| **USS Cerritos** | Cerritos | GTD | Chaos | Getting Things Done, Inbox Zero |
| **USS Protostar** | Protostar | DEAL | Liberation | Défaire les patterns anciens |

## 2. Frameworks en synthèse

### Ikigai (Orville)

```
Ikigai = Ce que j'aime × Ce que je sais faire
      × Ce dont le monde a besoin
      × Ce pour quoi je peux être payé
```

Donne le *pourquoi* derrière la mission A0.

### 12WY — 12-Week Year (SNW)

Méthode Brad Sugars : 12 semaines = un cycle d'exécution (pas 52). Forces : focus,
urgence, mesure. Cadence d'exécution pour tous les A2/A3.

### PARA (Enterprise) — Tiago Forte

- **P**rojects : initiatives actives avec deadlines
- **A**reas : responsabilités continues
- **R**esources : matériel de référence
- **A**rchives : inactif

Framework le plus cité (326 mentions en mars 2026).

### GTD — Getting Things Done (Cerritos) — David Allen

```
Capture → Clarify → Organize → Reflect → Engage
```

Gère le chaos de l'inbox quotidien.

### DEAL — Liberation (Protostar)

```
D Define (le pattern à briser)
E Examine (pourquoi il existe)
A Act (remplacer par un nouveau pattern)
L Lock (vérifier que le nouveau tient)
```

Transformation personnelle, pas exécution.

### Life Wheel (Discovery)

Équilibre sur 8 domaines de vie : Career / Finance / Health / Family / Social /
Personal Growth / Fun / Environment. Miroir de la structure Solaris OS.

## 4. Rôle de A0 dans la flotte

**A0 est le Pilot, pas un captain.** Il donne les intentions :

- À Rick (L0) pour l'infrastructure
- À Beth & Morty (L1) pour le meaning
- À Jerry & Summer (L2) pour le cashflow

Pattern E-Myth : A0 = Visionary, Beth/Morty = Manager, captains = Technician.
