# L2 Fractal B1/B2/B3 — Command Stack

> **Thèse** : dans L2 Business, le rang global A0-A3 est incarné en un stack vertical
> B1/B2/B3 (Direction → Domaines → Exécution), et ce stack **se répète à deux échelles** :
> la Area perpétuelle de Jerry (macro) et les projets Picard de Summer (micro).

## 1. B = A localisé à L2

| Stack L2 | = rang A | Acteurs | Possède |
|---|---|---|---|
| **B1 Direction** | A1 | Jerry (macro) + Summer (micro) | North Star, cycles 12WY, droits de décision, handoff queue, specs DoD/JTBD |
| **B2 Domaines** | A2 | les 8 héros-managers | DoD + gates de domaine, doctrine de principes perpétuels, control room |
| **B3 Warp Core** | A3 | les 8 squads Marvel/DC | exécution JTBD, preuve, lead/lag, peer-unblock |

**B1 = WHY/WHERE · B2 = WHAT/gate · B3 = HOW/proof.**

## 2. Le miroir fractal (macro ↔ micro)

- **Macro** = `02_Areas_Spock/J01_Jerry_Prime_LD01_Business/` (B1_Area_Direction /
  B2_Area_Domains / B3_Area_Warp_Core) — doctrine **perpétuelle**, source de vérité.
  Les Areas ne finissent jamais.
- **Micro** = `01_Projects_Picard/<projet>/` (B1_Summer_Direction / B2_Business_Domains /
  B3_Warp_Core_Execution) — **par projet**, **référence** la doctrine macro (DRY),
  calibre par mode (Solaris/Nexus/Orbiter). Les projets graduent ; les apprentissages
  remontent durcir la doctrine.

## 3. Flux + stop conditions

B1 mandate → B2 Rock+DoD → B2 JTBD → B3 exécute+preuve → B2 gates → B1 (drift only).

- Pas de B2 sans item B1
- Pas de B3 sans DoD/JTBD B2
