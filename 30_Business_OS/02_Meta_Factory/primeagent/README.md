# PrimeAgent

- **Role** : prototype d'agents franchises
- **Entree** : modele de franchise (ownerbook/SOP) a repliquer
- **Sortie** : prototype d'agent executable, limite au perimetre du modele
- **Invariant** : le prototype derives du modele source, jamais l'inverse ; aucune capacite non declaree dans le modele.
