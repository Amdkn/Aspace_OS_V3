## External research notes

### Arcade.dev
Arcade currently documents:
- OAuth 2.0 authorization-code flow, with/without PKCE;
- built-in and custom auth providers;
- per-user authorization context for agent tools;
- OAuth tokens/API keys/user tokens as managed authorization inputs.

Use this as a reference pattern, not as a mandatory vendor lock-in decision. Evaluate managed Arcade vs self-hosted equivalent vs thin provider adapters.

### Jules API
Official Google Jules API is currently alpha and exposes programmatic sessions/sources/activities. Current docs support session creation/listing/get, plan approval and messages. API keys are sensitive and must not be committed or embedded in prompts.
