## Handoff contract

Sessions exchange only durable references:

- IPBD UUID
- Linear issue ID
- Git commit/branch/PR
- Supabase work/evidence/event IDs
- test/evidence packet
- explicit acceptance status

Never hand off:
- hidden reasoning;
- "the other session knows";
- an unversioned local path as the only evidence;
- a conclusion without provenance.

## Cross-lane authority

Stewardship is accountability, not exclusive access.

A lane may read another surface when required. It must not mutate another lane's primary contract without durable handoff/evidence.

## Status truth

No lane may set Linear `In Progress` unless a live claim + active binding + freshly observed worker exist.

No lane may mark an IPBD resolved merely because a PR/ticket/document closed.

## Completion

Each lane exits with:
- outcome achieved or explicit blocker;
- durable evidence;
- exact next owner;
- no hidden session dependency.
