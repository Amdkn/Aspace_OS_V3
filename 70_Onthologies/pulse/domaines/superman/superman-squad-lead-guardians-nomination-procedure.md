# Superman — procédure de nomination du squad lead B3 Guardians

## Le trou canonique persistant vague 1-2-3-4-5

`superman-5-questions-ouvertes-cloture.md` (vague 2) note : *« 7ᵉ agent Guardians manquant dans substrat OMK »*. `superman-guardians-7th-agent-position.md` (vague 2) propose Peter_Quill_Orchestrator comme candidat principal, Nebula écarté (absorption IT). `superman-peter-quill-7th-agent-mandate-spec.md` (vague 4) spécifie le mandat H30 orchestrateur + fiche roster YAML Council-ready.

**Mais** aucun de ces concepts ne tranche **la question squad lead** — il y a une différence entre le 7ᵉ agent (qui complète la squad à 7) et le **squad lead** (qui signe le contrat B2 → B3 conjointement avec Superman, cf. `b2-b3-jtbd-handoff-contract.md` §« Le rôle du B3 squad lead »).

Le squad lead Guardians peut être :

- **Un des 6 agents existants** (StarLord_Story, Rocket_Auto, Gamora_Target, Drax_Closing, Groot_Content, Mantis_VoC) promu orchestrateur.
- **Le 7ᵉ agent** (Peter_Quill_Orchestrator ou Nebula_Analytics) si créé.

C'est un **trou canonique persistant** qui bloque le contrat bilatéral B2 → B3 pour les 6 agents Guardians (le mandat Peter_Quill vague 4 ne signe pas le contrat — il spécifie un profil).

## Pourquoi le squad lead est différent du 7ᵉ agent

Trois raisons structurelles (`b2-b3-jtbd-handoff-contract.md` §« Le rôle du B3 squad lead ») :

1. **Le squad lead tient le scrums.md du sprint** — chaque jour, une action exécutable (triplet 11). C'est un **mandat quotidien**, pas un mandat projet.
2. **Le squad lead signale les trous** au captain sponsor — *« je ne peux pas remplir ce DoD parce que X »*, sans tenter de combler (triplet 41). C'est un **rôle de vigilance**, pas un rôle d'exécution.
3. **Le squad lead livre la preuve** dans l'une des 4 formes canoniques (`b3-proof-path-4-formes`). C'est un **rôle de format**, pas un rôle de production.

Le 7ᵉ agent Peter_Quill (H30 orchestrateur brand/narrative, vague 4) est **mandat projet** — il orchestre les campagnes, il ne tient pas le sprint quotidien. Le squad lead est **un autre rôle** : quotidien, vigilant, format.

## Les 4 candidats squad lead — un par profil

### Candidat 1 — StarLord_Story (promu orchestrateur)

**Profil** : narrative, manifeste, brand storytelling (cf. `jtbd-emit-receive.md` ligne 43). Spécialisation brand — pas orchestration.

**Force** : cohérence avec Superman (les deux portent le brand voice). Cohérence avec People×Growth pair-check #11 Brand V5 (co-signature People).

**Faiblesse** : StarLord n'a pas de **vocation orchestration** — son profil est brand. Le promouvoir squad lead le déborde de son mandat.

### Candidat 2 — Rocket_Auto (promu orchestrateur)

**Profil** : automation marketing, séquences, paid ops (cf. `jtbd-emit-receive.md` ligne 45). Spécialisation automation — pas orchestration.

**Force** : **vocation exécution** alignée avec le mandat squad lead (quotidien, vigilant, format). Rocket est le B3 le plus proche du rôle canonique squad lead.

**Faiblesse** : Rocket porte déjà l'**automation** — la promotion squad lead le déborde sur 2 mandats (automation + orchestration). C'est un risque de **scope creep Squad Lead × Automation**.

### Candidat 3 — Peter_Quill_Orchestrator (7ᵉ agent + squad lead combiné)

**Profil** : H30 orchestrateur brand/narrative (cf. vague 4 mandat spec). Spécialisation orchestration — profil aligné avec le rôle squad lead.

**Force** : **création d'un rôle dédié** — Peter_Quill est mandaté pour l'orchestration, pas pour un autre B3. Combiné 7ᵉ agent + squad lead = **un seul mandat, deux rôles**.

**Faiblesse** : Peter_Quill n'est **pas encore créé** sur disque (cf. vague 4 §« Statut canonique »). La nomination squad lead = conditionnée à la création effective. **Trou canonique double** : 7ᵉ agent manquant + squad lead vacant.

### Candidat 4 — Nebula_Analytics (7ᵉ agent analytics, pas orchestrateur)

**Profil** : analytics/mixpanel (cf. `superman-guardians-7th-agent-position.md` §« Lecture 2 — Nebula_Analytics »). Spécialisation analytics — pas orchestration.

**Force** : **création d'un rôle manquant** (analytics stack est un trou canonique Superman↔IT pair-check #12 V5).

**Faiblesse** : profil **non aligné** avec le rôle squad lead (analytics ≠ orchestration). Nebula ne serait pas squad lead — elle serait **un agent analytics**, pas un orchestrateur.
