## Le test continuité 4D appliqué à Scarlet Witch H90

Le test continuité 4D (concept 1 tour 3) pose 4 questions sur un artefact. Pour un **agent opérationnel** (pas un artefact logiciel), les 4 questions se transposent :

### Dimension 1 — Continuité de build (qui construit si Scarlet Witch part ?)

**Question adaptée** : si Scarlet Witch quitte demain, **qui prend en charge la transformation scope** chez les Avengers ?

**Verdict** : ⚠️ **Continuité build partielle** — la transformation scope H90 est une **spécialité pointue** que Scarlet Witch porte seule. Captain America (H30) ne peut pas prendre sans formation H90 (3-6 sprints minimum). Aucun autre agent Avengers n'a la spécialité transformation scope (les 6 autres = Captain America orchestrateur + 5 spécialistes H10/H30 non-transformation).

**Conséquence** : Scarlet Witch est **person-named sur la dimension build** — la valeur de sa spécialité **dépend d'elle**. C'est l'inverse de ce que la doctrine valeur d'artefact exige.

**Risque veto Flash** : ⚠️ **potentiel** — si la transformation scope est une valeur d'offre (ex : « on transforme votre scope en 1 sprint H90 »), Scarlet Witch devient person-named sur cette offre. Le veto Flash peut s'opposer.

### Dimension 2 — Continuité de run (qui maintient la pratique transformation scope en run ?)

**Question adaptée** : si Scarlet Witch quitte, **Captain America peut-il maintenir la pratique transformation scope sans elle** ?

**Verdict** : ✅ **Run OK partiel** — Captain America H30 orchestrateur peut **déléguer** la transformation scope à un autre agent Avengers (par exemple Scarlet Witch → Hawkeye sur une transformation arrow-specific, Scarlet Witch → Vision sur une transformation density-specific), mais cela crée **une nouvelle dépendance person-named** (Hawkeye pour arrow, Vision pour density). Le **run décentralise** la dépendance sans la supprimer.

**Conséquence** : la pratique transformation scope est **maintenable** mais reste **person-named-distribuée**.

**Risque veto Flash** : ✅ **faible** — la pratique n'est plus adossée à Scarlet Witch seule, donc le veto Flash ne s'applique pas directement.

### Dimension 3 — Continuité de pivot (qui re-scope la transformation scope elle-même ?)

**Question adaptée** : si la **méthode** de transformation scope doit pivoter (ex : passer d'une approche itérative à une approche radicale), **qui re-pilote** ?

**Verdict** : ❌ **Pivot KO** — Scarlet Witch est **l'unique** agent capable de pivoter sa propre méthode. Captain America ne peut pas pivoter la méthode transformation scope (il n'a pas la spécialité H90). Aucun autre agent Avengers ne porte la méthode.

**Conséquence** : Scarlet Witch **est** la méthode transformation scope. La méthode meurt avec elle.

**Risque veto Flash** : ⚠️ **élevé** — la valeur de la méthode est person-named. Si l'offre Avengers comprend « méthode transformation scope Scarlet Witch », c'est exactement le cas que le veto Flash bloque (triplet 25 : *« bloque toute offre dont la valeur dépend d'une personne nommée »*).

### Dimension 4 — Continuité de sunset (qui décommissionne proprement ?)

**Question adaptée** : le jour où Avengers supprime la spécialité transformation scope, **qui gère la dépréciation sans casser les clients qui en dépendent** ?

**Verdict** : ✅ **Sunset OK** — la sunset d'une spécialité H90 est une décision Captain America (squad lead H30) + Flash (B2 Product), pas Scarlet Witch. Scarlet Witch **participe** au sunset mais ne le **pilote** pas. Le sunset est conforme au DoD 3 stades (concept 2 tour 3) § sunset.

**Conséquence** : Scarlet Witch **ne bloque pas** le sunset. Le risque veto Flash est nul sur cette dimension.

## L'asymétrie Wanda Maximoff vs Steve Rogers (canon Marvel)

Wanda Maximoff (Scarlet Witch) et Steve Rogers (Captain America) sont **2 figures Marvel** avec une asymétrie canonique importante :

- **Steve Rogers** (Captain America) : leadership **par le courage moral** (le sérum + le choix). Il est Captain America même sans le bouclier (Captain America sans uniforme reste Captain America).
- **Wanda Maximoff** (Scarlet Witch) : leadership **par la transformation reality** (ses pouvoirs mutent). Elle est Scarlet Witch **par ses pouvoirs**, pas par sa personne. Si elle perd ses pouvoirs, elle n'est plus Scarlet Witch.

**Conséquence** : Captain America est **structurellement dépersonnalisable** (sa valeur tient au rôle, pas à l'individu). Scarlet Witch est **structurellement personnalisée** (sa valeur tient à l'individu).

Cette asymétrie est **opposable au veto Flash** (triplet 25). Captain America peut être recommandé sans déclencher le veto (sa valeur est dans le rôle). Scarlet Witch **déclenche le veto** dès qu'elle est posée comme offre Avengers (sa valeur est dans l'individu, pas dans le rôle).

- **Confondre validation 4D et recommandation binaire** — le test 4D n'est pas oui/non. Scarlet Witch **réussit** sur 2 dimensions et échoue sur 2. La nuance compte.
- **Ignorer l'asymétrie Wanda/Steve** — Scarlet Witch est canoniquement personnalisée, Captain America structurellement dépersonnalisable. Cette asymétrie est **opposable au veto Flash**.
- **Recommander Scarlet Witch sans clause sunset** — la clause sunset datée est ce qui transforme le KO pivot en sunset-with-handoff. Sans clause, Issue B (packet bloqué).
