# Survival protocol — séquence 4 actions quand runway < 3 mois

## Pourquoi un protocole spécifique black phase

F1 runway doctrine (cf. `wonder-woman-f1-runway-doctrine-isolation.md`)
pose 4 phases (green >12 mois / amber 6-12 / red 3-6 / black <3).
La phase **black** (runway <3 mois) est l'urgence de survie — le
runway est si court qu'aucune action normale ne peut le restaurer à
temps.

Le **red flag #4** (cf. `wonder-woman-red-flag-4-trigger.md`) couvre
la phase rouge (runway <6 mois + Growth/Product green) — c'est un
**ralentissement ou re-pricing**, pas un protocole de crise.

Le protocole black phase est **distinct** du red flag #4 : il
couvre le moment où le cash est à un point de non-retour. Sans
protocole, le B2 Council est saisi en chaos — chacun propose une
action, personne ne séquence.

## La séquence 4 actions (sous 7 jours)

### Action 1 — Gel des dépenses non-essentielles (sous 24h)

**Responsable** : Wonder Woman (Finance) + Yelena Belova (B3 squad lead).

**Action** : Yelena produit la liste de toutes les dépenses
récurrentes/non-essentielles sous 4h. Wonder Woman oppose son veto
catalogue §06 à **toute nouvelle dépense récurrente** pendant 30
jours. Les dépenses gelées :

- Nouveaux SaaS, nouvelles licences logicielles.
- Recrutements non-essentiels (déjà couvert par Green Lantern §07).
- Marketing paid au-dessus d'un seuil de performance (déjà couvert
  par Superman §01).
- Voyages, formation, conférences.

**Exception** : les dépenses contribuant directement à augmenter le
MRR (ex. : sales enablement) restent autorisées, mais avec sign-off
WW explicite.

**Communication** : email à toute l'équipe sous 24h. Format :
« À compter de [date], toute dépense non-essentielle est gelée
jusqu'à [date]. Wonder Woman et Yelena sont les points de contact
pour les exceptions. »

### Action 2 — Communication transparente à l'équipe (sous 48h)

**Responsable** : Wonder Woman (Finance) + Green Lantern (People).

**Action** : Green Lantern convoque un all-hands sous 48h. Wonder
Woman présente la situation runway, le protocole de survie, et les
critères de succès. Pas de catastrophisme, pas de dissimulation —
la transparence est un **outil de mobilisation**, pas un aveu de
faiblesse.

**Script** :
- « Notre runway est à [X] mois. C'est court, mais nous avons un
  protocole. Les 4 actions couvriront 90 jours. Tout le monde
  contribue. »
- « Aucune décision de licenciement aujourd'hui. Si l'action 3
  (plan de continuité) ne suffit pas, le Conseil évaluera à J+30. »
- « Vos idées pour augmenter le MRR ou réduire les coûts sont
  attendues. Talk to your manager. »

**Anti-piège** : la communication **anticipe** les rumeurs. Sans
communication officielle, Slack devient un nid de spéculation qui
démoralise l'équipe.

### Action 3 — Plan de continuité 90 jours (sous 7 jours)

**Responsable** : Wonder Woman (Finance) + tous les capitaines B2.

**Action** : Yelena produit un plan de continuité 90 jours avec
**réduction opex ≥ 30%** OU **augmentation MRR ≥ 30%** (ou les
deux). Le plan est soumis au B2 Council pour adoption.

**Format** :
- Cible : extension runway à 6+ mois d'ici J+90.
- Opex reduction : ligne par ligne, par catégorie, avec impact
  runway.
- MRR acceleration : ligne par ligne, par capitaine, avec impact
  runway.
- Risques : vendor churn, employé churn, client churn.

**Example** :
- Coupe SaaS Zapier ($50/mois) + Notion AI ($20/user) = $290/mois
  (sur 14 users).
- Renégociation cloud (AWS) : -15% via Savings Plan = $1 200/mois.
- Gel recrutement 2 postes Q+1 = $30k/mois économisés.
- Total reduction opex : ~$32k/mois, soit ~$96k sur 90 jours.

### Action 4 — Escalade B1 par escalier canonique (sous 7 jours)

**Responsable** : Wonder Woman (Finance) → B2 Council → B1 (Summers).

**Action** : à J+7, si le plan de continuité est adopté mais le
runway reste < 3 mois, escalade B1 par l'escalier canonique 5
échelons (cf. `b1-stop-conditions-escalier.md`).

**Format packet mésoperpétuel** :
```yaml
meso_decision_id: B2-MESO-DECISION-YYYY-NN
source_mandate: B2-PEER-YYYY-NN
mode: negotiation
impacted_domains:
  - finance
  - product
  - growth
  - sales
  - people
tradeoff: "Runway < 3 mois, plan de continuité 90 jours adopte.
  Escalade B1 pour arbitrage cycle 12WY (extension, pivot, ou
  fermeture)."
decision: escalate_to_B1
proof_expected:
  - B1 escalate trigger (Summers convoque)
  - B2 gate finance update (runway_mois_post_action)
  - B3 proof path (plan_continuite_90j_adopte)
next_review: 14_days
```

## 4 cas légitimes + 3 cas abusifs

### Cas légitimes (le protocole s'applique)

1. **Runway passe de 4 à 2.5 mois suite à un pivot raté.** Action 1
   gel immédiat, action 2 all-hands, action 3 plan 90 jours, action
   4 escalade B1.
2. **Runway 2 mois avant une Series A milestone.** Action 1 gel,
   action 2 communication, action 3 plan + relance investisseurs,
   action 4 escalade B1 pour ré-étalonnement cycle.
3. **Runway 1.5 mois avec acquisition en cours.** Action 1 gel + due
   diligence financing, action 2 communication corps social, action
   3 plan + bridge loan, action 4 escalade B1.
4. **Runway 2 mois + red flag cumulatif (Finance red + Product red).**
   Action 1 gel, action 4 escalade B1 immédiate (plan 3 combine
   reduction opex + p暂停 product).

### Cas abusifs (le protocole serait abusif)

1. **Protocole black phase brandé sans runway < 3 mois.** Si runway
   4-5 mois, le protocole est **disproportionné**. Le red flag #4
   suffit. WW abuse si elle déclenche le protocole black phase par
   excès de prudence.
2. **Gel total des dépenses sans nuance.** Le gel total paralyse
   l'opération. WW abuse si elle oppose veto §06 à toutes les
   dépenses, y compris celles qui augmentent le MRR.
3. **Communication catastrophiste.** « On va fermer dans 3 mois » —
   c'est de la **démoralisation**, pas de la transparence. Le script
   d'action 2 est précis : constat + protocole + critères de succès.
4. **Escalade B1 sans plan de continuité.** L'escalade B1 est
   **accompagnée** d'un plan. WW abuse si elle escalade B1 en
   demandant à Summers de trouver le plan.

## Anti-pièges

- **Runway < 3 mois sans déclencher le protocole.** Le seuil est
  binaire. Si runway = 2.9 mois, le protocole est obligatoire. WW
  abuse si elle temporise par peur de la connotation.
- **Protocole déclenché sans communication.** La communication
  officielle (action 2) est un **multiplicateur de mobilisation**,
  pas un détail. Sans elle, les gens sous-optimisent par peur.
- **Plan de continuité sans opex reduction chiffrée.** Un plan
  vague (« on va réduire les coûts ») est un voeu pieux. Yelena
  produit le plan, mais WW challenge ligne par ligne.
- **Escalade B1 court-circuitant le Council.** Si l'échelon 3 du
  Council (cf. escalier canonique) n'a pas validé le plan, WW abuse
  si elle escalade directement B1.
